      Developer Kit

      The basket is the payment amount

      gvm.js reads data-gvm-price once, at boot — so the page keeps it out of <head>, computes the total, sets the attribute and only then imports the module.

      1. Configure. The customer edits the brief and toggles deliverables. The total is computed in minor units on the client.
      2. Bind. On checkout the page writes data-gvm-price, data-gvm-reference and data-gvm-metadata-title on #basket-trigger and appends the gvm.js module.
      3. Pay. The hide strategy with no split config injects only the bound CTA; clicking it opens the standard QR + SMS dialog and creates the commitment for the basket amount.
      4. Change. If the basket changes after boot, the reference is reloaded with ?checkout=1 so the amount is never stale.

      Minimal dynamic-amount snippet

      Source on GitHub | gvm.js documentation

      Set the price, then load gvm.js 
      <!-- 1) Initialize gvm on body (no SDK in <head>) -->
<body data-gvm data-gvm-tenant="your_tenant" data-gvm-env="qa"
      data-gvm-currency="PLN" data-gvm-callback="basketPaymentCallback">

  <!-- 2) Hidden trigger + pay CTA injected by the hide strategy -->
  <div id="basket-trigger" hidden
       data-gvm-template-name="payment"
       data-gvm-hide-template-name="basket-cta"
       data-gvm-hide-strategy="hide"></div>

  <template data-gvm-template="basket-cta" data-gvm-template-inject-to="#basket-cta-slot">
    <p>Dostęp do tej Treści jest odpłatny: <strong><span data-gvm-bind-price></span>&nbsp;<span data-gvm-bind-currency></span></strong> …</p>
    <button data-gvm-bind-pay>Pay <span data-gvm-bind-price></span> <span data-gvm-bind-currency></span></button>
  </template>

<script>
  // 3) The basket total exists only after the customer configures it:
  const total = 12.95;                 // e.g. 2.99 + 3.99 + 5.99
  const trigger = document.getElementById('basket-trigger');
  trigger.setAttribute('data-gvm-price', total.toFixed(2));
  trigger.setAttribute('data-gvm-reference', 'logokit_northwind_1a2b3c4d');
  // 4) Only now import the module — it binds price/reference at boot
  const s = document.createElement('script');
  s.type = 'module';
  s.src = 'https://esm.sh/@wdft/gvm-sdk@latest/gvm.js';
  document.head.appendChild(s);
</script>
      Production note: the browser computes the total, so a customer could tamper with it. A real app should compute the basket server-side and mint a signed data-gvm-price-token for the amount, then verify the commitment signature before delivering the assets. See the gvm.js docs → Price token.
